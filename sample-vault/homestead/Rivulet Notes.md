# Rivulet Notes

The side tool. Estimates a site's water budget: rain in, evapotranspiration and
runoff out, supplemental irrigation needed for a given plant palette.

Where it stands: it runs and it feeds two live jobs (the Larkspur slope and the
Hollis rain garden). Input is a CSV, output is a one-page summary. That is the
whole scope and it should stay that way.

Idea parking lot, deliberately not built: multi-season modeling, a map view, a
plant-database live link. Tempting, all of it, none of it worth the complexity
yet. Keep it small.
