When Maya asks where a project landed on something, read the project note before
answering. Twice now the assistant has reconstructed a decision from memory and
gotten a detail wrong that was written down correctly in the note. The corpus is
the source of truth; memory is a shortcut that fails on specifics.

**Why:** The Larkspur maintenance-plan scope and the Hollis well question were
both answered from memory and corrected against the written note in the same
session. Two misses, same shape.
**How to apply:** Any question naming a project, a plant, a date, or a number
gets a note read first. Answer from the note, cite it, and only then add
judgment on top.
